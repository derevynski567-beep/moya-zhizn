# Моя жизнь

Мобильный планировщик на русском языке: план дня, личный журнал, рабочие объекты и учёт денег.

## Что уже есть в прототипе

- План дня: задачи с отметкой выполнения, расписание по времени и заметка дня.
- Личный журнал с записями по датам.
- Рабочие объекты: заказчик, цена договора, статус и примечания.
- Доходы и расходы по категориям, с привязкой к объектам.
- Автоматический расчёт прибыли объекта, маржи, поступлений, расходов и денежного результата.
- Автоматическое сохранение в браузере.
- Экспорт резервной копии в JSON.
- Адаптивный интерфейс для Safari на iPhone, PWA-манифест и офлайн-кэш.

## Как включить GitHub Pages

1. Открой Settings → Pages в этом репозитории.
2. В разделе Build and deployment выбери источник GitHub Actions.
3. Проверь Actions: workflow `.github/workflows/pages.yml` должен запуститься после коммита.
4. После успешного завершения адрес приложения появится в Settings → Pages.

Доступность Pages для приватного репозитория зависит от тарифа GitHub. Если в настройках нет нужного варианта, исходный код можно оставить приватным и отдельно решить, где публиковать собранное приложение.

## Важно про хранение данных

Пока записи хранятся в localStorage конкретного браузера на конкретном устройстве. Они не синхронизируются автоматически с другими устройствами и не являются облачной базой. Используй экспорт JSON для резервных копий. Не храни чувствительные данные в этом прототипе.

## Формулы

- Прибыль объекта = цена договора − зарегистрированные расходы объекта.
- Поступления показываются отдельно: это полученные деньги, а не полная цена договора.
- Денежный результат = все фактические поступления − все фактические расходы.
- Маржа = прибыль объекта / цена договора × 100%.

Это персональный прототип, а не полноценная бухгалтерская система; сверяй данные с первичными документами.
